## 📌 Section 1 — 패턴 식별 (이런 문제 나오면 발동)

> **패턴 정의** (한 줄)
> DFS는 **그래프/트리에서 깊이 먼저 끝까지 들어갔다 빠지는** 탐색. 재귀 또는 스택. → "모든 경로 / 연결 요소 / 도달 가능성" 키워드 나오면 1순위 후보.

### 1-1. 판별 신호 (문제 키워드 → 패턴 매핑)

- `connected component` / `island` / `region` → DFS/BFS (연결 컴포넌트)
- `all paths` / `enumerate paths` / `permutation` → DFS (백트래킹 결합)
- `이동 가능 / 도달 / 갈 수 있는` (한국어 문제) → DFS/BFS
- `tree traversal` / `subtree sum` → DFS (트리 재귀)
- `cycle detection in directed graph` → DFS (3색 마킹)
- `최단 거리`가 나오면 → ❌ DFS 아님 (BFS 또는 다익스트라)

### 1-2. 실제 문제 예시 (대표 5-6개)

**섬 개수 / 연결 컴포넌트**
- *Number of Islands* — `#200-LC` (Medium, grid DFS 기본형)
- *단지번호붙이기* — `B-2667` (정자, grid + 컴포넌트 크기)
- *바이러스* — `B-2606` (인접 리스트 + 카운트)

**모든 경로 탐색 (백트래킹 결합)**
- *All Paths From Source to Target* — `#797-LC` (DAG, 경로 수집)
- *N-Queens* — `#51-LC` (Hard, 가지치기 + DFS)
- *알파벳* — `B-1987` (visited bitmask로 알파벳 중복 차단)

**트리 재귀**
- *Maximum Depth of Binary Tree* — `#104-LC` (Easy, 깊이 = max(좌, 우) + 1)

### 1-3. 안 들렸을 때 안전망 (다른 패턴 혼동 시)

| 헷갈리는 패턴 | DFS와의 차이 |
|---|---|
| **BFS** | 최단 거리(가중치 1)면 무조건 BFS. DFS는 "모든 경로 / 도달성" 전용. |
| **다익스트라** | 가중치 있는 최단거리 → 다익스트라. DFS는 가중치 무시. |
| **유니온파인드** | 연결 컴포넌트만 묻고 그래프 동적 갱신 있으면 UF. 정적 그래프면 DFS도 OK. |
| **DP** | 같은 상태 반복 호출 + 결과 재사용 → DFS+memo (= top-down DP). |

### 1-4. 첫 30초 체크 (시간복잡도 / N 범위 / 자료구조)

| 신호 | 발동 |
|---|---|
| 정점 V, 간선 E → `O(V+E)` 가능 | 인접 리스트 DFS |
| 격자 R×C ≤ 1000×1000 | grid DFS 재귀 (단, Python은 sys.setrecursionlimit) |
| N ≤ 20, "모든 경우" | 백트래킹 DFS (2^N 또는 N!) |
| N ≥ 100,000 + "최단" | ❌ DFS 버려라 (BFS/다익스트라/세그트리) |
| 재귀 깊이 ≥ 10^4 위험 | 명시적 stack으로 변환 |

## 📌 Section 2 — 단계별 ★ 임무 (5줄)

> 시험장 풀이 시작 직전 머리에 새기는 5줄. 각 단계마다 **딱 하나의 동작 지령**만 본다.

| 단계 | ★ 임무 한 줄 | 핵심 동작 |
|---|---|---|
| **입력 파싱** | **자료구조 만들기 전에 입력 형식 1줄 적기** | `N M / 간선 M개` 등 주석 한 줄. 1-based vs 0-based 즉시 결정. |
| **자료구조 선택** | **그래프 표현 정하기 (인접 리스트 / 격자 / 트리)** | 정점 ≤ 10^5 → 인접 리스트. 격자 그대로면 board 2D. |
| **알고리즘 적용** | **재귀 골격 3줄: 종료조건 → 방문체크 → 재귀호출** | visited 배열 잡고 시작점부터 호출. 함수 시그니처 먼저. |
| **엣지케이스** | **빈 입력 / 단일 노드 / 사이클 / 연결 안 된 노드 확인** | 격자면 모서리, 트리면 leaf, 그래프면 고립 정점. |
| **출력 형식** | **출력 1줄 vs 여러 줄 / 정렬 여부 확인** | 백준은 `print` 한 줄에 1개. LC는 list return. 순서 요구 있으면 sort. |

## 📌 Section 3 — 패턴 코어 메커니즘 + N개 시동

> **코어 메커니즘 (한 줄)**: DFS의 본질은 **"방문 표시 → 재귀 호출 → (필요 시) 방문 해제"** 3박자. 방문 해제 여부가 **컴포넌트 카운팅(해제 X)** vs **백트래킹(해제 O)**을 가른다.

### 3-1. N개 시동 도구함 (자주 쓰는 골격)

**시동 1 — Grid DFS (섬 개수형)**
```
def dfs(r, c):
    if r<0 or r>=R or c<0 or c>=C: return
    if board[r][c] != '1': return
    board[r][c] = '0'        # 방문 표시 = 칸 덮어쓰기
    for dr,dc in [(-1,0),(1,0),(0,-1),(0,1)]:
        dfs(r+dr, c+dc)
```

**시동 2 — 인접 리스트 DFS (연결 컴포넌트)**
```
def dfs(u):
    visited[u] = True
    for v in adj[u]:
        if not visited[v]:
            dfs(v)
```

**시동 3 — 백트래킹 DFS (모든 경로)**
```
def dfs(u, path):
    if u == target:
        result.append(path[:]); return
    visited[u] = True
    for v in adj[u]:
        if not visited[v]:
            path.append(v); dfs(v, path); path.pop()
    visited[u] = False       # ★ 백트래킹은 해제 필수
```

### 3-2. 시동 선택 트리

| 문제 묻는 것 | 시동 |
|---|---|
| 격자에서 '같은 색' 영역 개수/크기 | 시동 1 |
| 그래프에서 컴포넌트 개수 | 시동 2 |
| 모든 가능한 경로 / 순열 / 조합 | 시동 3 |

## 📌 Section 4 — 코드 스니펫 본체 (Python 우선)

> 시험장에서 바로 복붙 가능한 5-10줄 단위. 출처 표기는 **실전 검증된 문제**만.

### 4-1. 섬 개수 (Number of Islands) — `#200-LC`

```python
def numIslands(grid):
    if not grid: return 0
    R, C = len(grid), len(grid[0])
    def dfs(r, c):
        if r<0 or r>=R or c<0 or c>=C or grid[r][c]!='1': return
        grid[r][c] = '0'
        for dr,dc in [(-1,0),(1,0),(0,-1),(0,1)]: dfs(r+dr,c+dc)
    cnt = 0
    for r in range(R):
        for c in range(C):
            if grid[r][c]=='1':
                dfs(r,c); cnt += 1
    return cnt
```
- **시간**: O(R·C) **공간**: O(R·C) (재귀 스택 최악)

### 4-2. 연결 컴포넌트 (바이러스) — `B-2606`

```python
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline
N = int(input()); M = int(input())
adj = [[] for _ in range(N+1)]
for _ in range(M):
    a, b = map(int, input().split())
    adj[a].append(b); adj[b].append(a)
visited = [False]*(N+1)
cnt = 0
def dfs(u):
    global cnt
    visited[u] = True; cnt += 1
    for v in adj[u]:
        if not visited[v]: dfs(v)
dfs(1)
print(cnt-1)
```
- **시간**: O(V+E)
- **함정**: 백준 Python은 재귀 한도 + `sys.stdin.readline` 거의 필수.

### 4-3. 트리 최대 깊이 — `#104-LC`

```python
def maxDepth(root):
    if not root: return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
```
- **시간**: O(N) **공간**: O(H) (H=트리 높이)

### 4-4. 백트래킹 — 모든 경로 — `#797-LC`

```python
def allPathsSourceTarget(graph):
    n = len(graph); res = []
    def dfs(u, path):
        if u == n-1:
            res.append(path[:]); return
        for v in graph[u]:
            path.append(v); dfs(v, path); path.pop()
    dfs(0, [0])
    return res
```
- **시간**: O(2^N · N) (DAG, 최악)

## 📌 Section 5 — 보너스 규칙

### 5-1. 시간복잡도 등급 표

| N 범위 | 허용 복잡도 | DFS 적용 |
|---|---|---|
| N ≤ 10 | O(N!) | 백트래킹 풀가지 |
| N ≤ 20 | O(2^N) | 비트마스크 + DFS |
| N ≤ 500 | O(N^3) | Floyd 등, DFS는 보조 |
| N ≤ 5,000 | O(N^2) | 인접 행렬 DFS |
| N ≤ 100,000 | O(N log N) | 인접 리스트 DFS (V+E) |
| N ≤ 1,000,000 | O(N) | DFS 가능 단, **재귀 X → 스택 변환** |

### 5-2. 자주 빠뜨리는 디테일

- **방문 배열 초기화**: 다음 테스트케이스에서 안 비우면 누적 버그. `for _ in range(T)` 안에서 매번 새로.
- **격자 방향**: `dr,dc` 4방향과 8방향 헷갈리지 마라. 문제에 "대각선 포함" 단어 있으면 8방향.
- **1-based vs 0-based**: 백준 정점 1-based 많음. `adj = [[] for _ in range(N+1)]` 습관.
- **루트 visited 표시**: 시작점도 visited 찍어야 사이클에서 무한 재귀 안 빠짐.
- **백트래킹 path 복사**: `res.append(path)`는 참조 공유 버그. `res.append(path[:])` 필수.

### 5-3. 언어별 함정

| 언어 | 함정 |
|---|---|
| **Python** | 재귀 한도 1000 → `sys.setrecursionlimit(10**6)`. 함수 호출 오버헤드 큼 → 격자 큰 문제는 stack 변환 또는 BFS. |
| **JS** | 재귀 한도 ~10000, 안정적이려면 명시적 stack. `Map` vs `Object` — 정수 키만 쓰면 배열 더 빠름. |
| **C++** | 재귀 한도 OS 스택 의존 (~1MB). 큰 격자는 `vector<vector<int>>` 보다 1D 평탄화가 캐시 친화. |
| **Java** | `ArrayList` 인접 리스트 충분. StackOverflowError 자주 → `-Xss` 옵션 또는 iterative. |

## 📌 부록 B — Easy / Medium / Hard 갈림길

> 같은 패턴이 난이도별로 어떻게 변형되는지. 시험장에서 "이거 어느 단계지?" 즉시 판단용.

### Easy — 골격 그대로

- **`#104-LC` Max Depth of Binary Tree** — 재귀 3줄. 종료조건 + max(좌, 우) + 1.
- **`B-2606` 바이러스** — 시동 2 그대로 복붙 + 카운트.
- **공통 신호**: "개수 세기 / 깊이 / 단일 컴포넌트". 가지치기 없음.

### Medium — 시동 + 1개 트릭

- **`#200-LC` Number of Islands** — 시동 1 + **방문 표시 = 칸 덮어쓰기** 트릭 (visited 배열 안 써도 됨).
- **`B-2667` 단지번호** — 시동 1 + **컴포넌트별 크기 수집 + 정렬 출력**.
- **`#797-LC` All Paths** — 시동 3 + DAG라서 **visited 해제 불필요** (사이클 없음).
- **공통 신호**: 시동에 **출력 가공 / 방문 표시 변형 / 사이클 유무 판단** 1개 추가.

### Hard — 시동 + 2개 이상 트릭 (가지치기 / 메모이제이션 / 상태압축)

- **`#51-LC` N-Queens** — 시동 3 + **가지치기 (대각선/열 충돌)** + **bitmask 최적화**.
- **`B-1987` 알파벳** — 시동 1 + **bitmask로 알파벳 26개 방문 상태** + **백트래킹 해제**.
- **사이클 있는 그래프의 모든 경로** — 시동 3 + **visited 해제** + **path 중복 방지**.
- **공통 신호**: 단순 DFS로는 시간초과. **상태 압축, 가지치기, memo** 중 2개 이상 결합.

### 난이도 점프 시그널 (체크리스트)

- [ ] 가지치기 조건 1개라도 있나? → Medium 이상
- [ ] 상태가 (정점, 비트마스크) 등 다차원인가? → Hard 가능성
- [ ] 같은 상태 재방문 가능한가? → memo 필요 → Hard (= DP)
- [ ] 시간복잡도 계산이 O(V+E)로 안 끝나나? → Hard (백트래킹 + 가지치기 필수)
