오픽 IH 합격 (2026-05-29)으로 검증된 학습 시스템을 코딩테스트 등 다른 도메인으로 이전 중.

**Why:** 도메인 무관 학습 메커니즘이 입증됨. 자료 / 에이전트 / 추적 시스템을 재사용 가능.

**How to apply:**

### 엔진 5요소 (도메인 무관)
1. **양치기** — 같은 골격 다른 표면 N회 연속 (#15→#16에서 +1.25점 폭발 증명)
2. **4층 채점** — 구조 / 패턴 / 표현 / 디테일 (오픽=단원/콤보/감정/부사 → 코테=알고리즘/자료구조/구현/엣지)
3. **약점 추적 매트릭스** — 약점 누적 + 다음 향상 포인트 + 마일스톤
4. **트리거** — 인지≠실행 약점 극복용. 진입 지점에 트리거 박기 (오픽 ER 시제 = 코테 엣지케이스)
5. **약점 속도 3분류** — 명확규칙(빠름) / 자동화필요(트리거) / 정체성거부(인내)

### 사용자 개인 성향 (도메인 무관, 양보 불가)
- **앵커부터 못박는 변형형** — 빠른 구조, 느린 마무리 (시제·짝짓기·엣지케이스는 의식적 트리거 필요)
- **강요 거부 / 노출엔 자발** — AL/어려운 패턴 강제 X. 양치기로 노출 시 자발 시도 (5회 뒤 평균)
- **검증된 골격만 신뢰** — 분석가 라벨·새 패턴명 거부. 강의자료(레퍼런스 코드) 그대로 차용 선호
- **자기 함정**: 갈래 증식 / 추상 라벨 만들기 / 한 번에 너무 많이 / 메타인지로 본인 약점 알지만 실행 누락

| 약점 | (시험_기록 누적) | files/약점_체크리스트.md |

### 에이전트 3종 구조 (도메인별)
- **모의시험** — 출제 + 4층 채점 + 양치기 모드 + 추적 갱신
- **카탈로그 생성** — 단원/패턴 범용. 가드레일 G1~G6
- **카탈로그 검증** — 9항목 외부 검증 (V2 코어 메커니즘이 절대 기준)

### 도메인 신규 추가 절차
1. [files/학습_메타_노트.md](files/학습_메타_노트.md) 정독 (도메인 무관 메타)
2. 카탈로그 시드 복제 → 7섹션 채움
3. 에이전트 3종 도메인 치환 (단어만 바꾸고 골격 유지)
4. 추적 시스템 (코테_기록.md 양식) 복제
5. 첫 양치기 사이클 → 약점 누적 → 트리거 박기

### 오픽에서 검증된 결론 (코테에도 적용)
- "낯선 토픽 → 쉬운 단어로" = "모르는 문제 → brute force부터"
- "AL 강요 거부" = "어려운 패턴 강요 거부 OK"
- "5회 뒤 자발 시도" = 어려운 콤보·패턴은 노출 누적이 필요
- "한 번에 1-2개만 수정" = 점진적 향상
