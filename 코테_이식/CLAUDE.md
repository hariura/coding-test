## 무엇을 하는 프로젝트인가

알고리즘 코딩테스트(LeetCode / 백준 / 프로그래머스)를 **양치기 시스템**으로 학습한다.

오픽 IH 합격(2026-05-29)으로 검증된 학습 엔진을 코딩테스트 도메인으로 이식한 시스템:
- **양치기** — 같은 패턴 다른 문제 3연속
- **4층 채점** — 정확성 / 시간복잡도 / 구현 / 엣지케이스
- **약점 추적** — 매 풀이 후 코테_기록.md 갱신, 반복 약점 → 트리거
- **트리거** — 인지≠실행 약점에 진입 지점 알람

## 핵심 결론 (오픽에서 검증된 원리)

1. **양치기 3요소 + 2보조** — 즉각성·같은골격·집중 (사이클) + 누적·트리거 (인프라). 학습_메타_노트 §3-2 본체.
2. **사용자 코드 살려라** — 모범답안은 사용자 코드 베이스 + 시간복잡도·엣지케이스 최소 수정. 통째 재작성 X.
3. **빡센 문제 OK, 답·해설은 무조건 쉽게** — 고급 트릭/원라이너 강요 X. AL 강요 거부 = 코테에서 어려운 패턴 강요 X.
4. **약점 속도 3분류** — 명확규칙(빠름) / 자동화(트리거) / 정체성(인내). 트리거 박을 약점 선별.
5. **패턴 단위 묶음 학습 > 문제 단위 랜덤** — 오픽 콤보셋 = 코테 양치기.

## 가드레일 (반복 함정)

- ❌ 분석가 라벨 새로 만들기 — 정해진 패턴명만 (BFS / DFS / DP / 투포인터 / 슬라이딩윈도우 / 백트래킹 / 그리디 / 이분탐색 / 다익스트라 / 유니온파인드)
- ❌ 한 번에 5개 피드백 — 1~2개만
- ❌ 모범답안에 사용자가 안 쓴 고급 문법 추가 — bisect/heapq 강요 X
- ❌ 카탈로그 600줄 초과 — 시험장에서 못 씀
- ❌ "이것도 알면 좋아요" 부록 — 메인 라인만
- ❌ 한 작업 끝나면 자동 진행 — 사용자에게 "다음 뭐?" 물어라
