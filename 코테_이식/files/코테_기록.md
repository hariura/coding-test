## 패턴별 코어 메커니즘 (외우기용)

> 단원 카탈로그처럼 각 패턴의 "1줄 코어"를 박아둔다. 풀이 시작 전 30초 멈춤 → 어떤 코어로 풀지 결정.

| 패턴 | 코어 메커니즘 (한 줄) | 신호 (이거 보이면 이 패턴) |
|---|---|---|
| 이진탐색 | 정렬된 공간을 절반씩 잘라 답 후보를 줄임 | "최소·최대 N 중에서", "단조함수" |
| BFS | 큐로 레벨별 확장 → 최단거리 | "최소 칸 수", "가까운 순서대로" |
| DFS | 스택/재귀로 끝까지 → 경로 / 백트래킹 | "모든 경우", "조건 맞는 경로" |
| DP | 부분문제 점화식 + 메모 | "최대·최소·경우의 수" + 중복 부분문제 |
| 슬라이딩윈도우 | 윈도우 크기 유지·확장하며 좌우 포인터 | "연속 부분배열", "K개 윈도우" |
| 투포인터 | 정렬 후 양끝 좁히기 | "합이 X", "쌍 찾기" |
| 그리디 | 매 단계 국소 최적 → 전체 최적 (증명 필요) | "최소 횟수", 정렬 후 한 번 훑기 |
| 백트래킹 | DFS + 가지치기 (실패 시 되돌리기) | "조합", "순열", "조건 충족 모든 경우" |
| 유니온파인드 | 집합 합치기 + 루트 찾기 | "연결 여부", "그룹 개수" |
| 해시 | O(1) 룩업으로 중첩 루프 제거 | "X 짝 찾기", "중복 카운트" |
| 스택 | LIFO, 직전 상태 되돌리기 | "괄호", "직전 값 비교" |
| 큐 | FIFO, 들어온 순서대로 처리 | "줄서기", "프린터 큐" |
| 트리 순회 | 전위/중위/후위 + 레벨 | "부모-자식", "깊이별 처리" |
| 그래프 탐색 | 정점-간선 모델링 + BFS/DFS | "도시 N개 연결", "방문 가능?" |
| 비트마스킹 | 부분집합을 정수 비트로 표현 | "N≤20", "부분집합 DP" |

## 학습 루틴 (오픽 카탈로그 방식 차용)

1. **풀이 전 30초 멈춤**: 패턴 식별 + 코어 메커니즘 입으로 말하기
2. **풀이 중 시간 측정**: 30분 넘으면 해설 보고 OK (대신 본 시점 기록)
3. **풀이 직후 즉시 기록**: 미루지 말고 이 파일에 바로 추가
4. **주 1회 메타 리뷰**: 위 "자주 나오는 약점 패턴" 업데이트
5. **양치기 묶음 완주 후**: 묶음 표에 평균·상승폭 기록, 다음 패턴으로 이동
6. **저장 전 사용자 확인**: 큰 수정은 본인이 한 번 훑고 commit (오픽 모의시험 저장 흐름과 동일)

## 시간복잡도 빠른 참조

> 입력 크기 N → 허용 복잡도 가이드 (1초 기준).

| N 범위 | 허용 복잡도 | 대표 패턴 |
|---|---|---|
| N ≤ 10 | O(N!) | 순열·완전탐색 |
| N ≤ 20 | O(2^N) | 비트마스킹·부분집합 |
| N ≤ 500 | O(N³) | 플로이드·삼중 DP |
| N ≤ 5,000 | O(N²) | DP·이중 루프 |
| N ≤ 100,000 | O(N log N) | 정렬·이진탐색·세그트리 |
| N ≤ 1,000,000 | O(N) / O(N log N) | 투포인터·슬라이딩윈도우 |
| N ≤ 10^9 | O(log N) / O(√N) | 이진탐색·수학 |
