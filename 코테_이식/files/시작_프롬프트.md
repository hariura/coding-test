# 코딩테스트 학습 세션 시작 프롬프트

> 새 클로드 세션에서 코딩테스트 학습 시작할 때 이 마크다운 코드 블록 복붙.
> 메인 세션에서 자료/에이전트/시스템 셋업 완료. 새 세션은 그대로 받아서 진행.

---

## 🚀 새 세션에 던질 프롬프트 (복붙)

```markdown
# 코딩테스트 학습 세션 시작

이 폴더(/Users/jh/Desktop/vs)는 오픽 OCR 프로젝트지만 코딩테스트 도메인도 같이 운영.
메인 세션에서 자료/에이전트를 모두 셋업해놨으니 그대로 받아서 진행.

## 0. 먼저 정독 (이 순서대로)

1. **사용자 성향** ← 가장 먼저
   - files/학습_메타_노트.md (양치기 3요소+2보조 / 약점 3분류 / 강점·함정)
2. **추적 시스템 (사용자 수준 확인)**
   - files/코테_기록.md (없으면 첫 풀이부터 시작)
3. **공용 풀**
   - files/약점_체크리스트.md (트리거 + 엣지케이스 5종 + 3분류 엔진)
   - files/즉각대응_플레이북.md (모르는 문제 30초 행동 + N 범위 매핑)
4. **패턴 카탈로그 시드**
   - 카탈로그/패턴_시드.md (7섹션 골격 — 패턴 카탈로그 만들 때 복제)
5. **에이전트 (필요시 호출)**
   - agents/모의시험.md (출제·4층 채점·양치기)
   - agents/카탈로그_생성.md (패턴 카탈로그 빌더)
   - agents/카탈로그_검증.md (카탈로그 검증)
6. **이미 작성된 패턴 카탈로그** (있는 만큼)
   - 카탈로그/{패턴}_A.md (BFS_A.md / DFS_A.md / DP_A.md 등 — 작성됐을 시)

## 1. 사용자 성향 (핵심만 — 상세는 학습_메타_노트)

- **빡센 문제 OK, 답·해설은 무조건 쉽게.** 고급 트릭/원라이너 주입 X.
- **한 번에 1~2개만 수정.** 5개 던지면 흡수 못 함. 끊고 피드백.
- **사용자 코드 살려라.** 모범답안은 사용자 코드 베이스 + 시간복잡도·엣지케이스만 최소 수정.
- **패턴 fidelity.** 한 변형만 보여주고 일반화 X. 카탈로그에 나온 변형 전부 노출.
- **분석가 라벨 새로 만들지 마.** 정해진 패턴명만 (투포인터, 슬라이딩윈도우, BFS, DFS, DP, 백트래킹, 그리디, 이분탐색).
- **강요 거부 → 노출엔 자발.** 어려운 패턴 강요 X. 양치기 누적되면 자발 시도 (5회 뒤 평균).

## 2. 첫 작업 (3가지 옵션)

사용자가 A/B/C 중 하나 고르면 해당 에이전트 호출.

### A. 첫 패턴 카탈로그 생성 (권장 — 골격부터)

agents/카탈로그_생성.md 읽고 그 지시 따라.
- 패턴: BFS (또는 DP, 투포인터 등 사용자 지정)
- 시드: 카탈로그/패턴_시드.md 복제
- 산출물: 카탈로그/{패턴}_A.md

### B. 첫 모의시험 (문제 풀이)

agents/모의시험.md 읽고 그 지시 따라.
- 출제 → 답변 → 4층 채점 → 코테_기록.md 갱신
- 양치기 모드 가능 ("양치기" + 패턴 명시)

### C. 양치기 모드 (같은 패턴 3연속 — 가장 강력)

agents/모의시험.md 읽고 양치기 모드로 진행.
- 패턴: DP (또는 사용자 지정)
- Q1 1차원 → Q2 2차원 → Q3 비트마스킹 (난이도 점증)
- 3문제 끝나면 종합 평가 + 코어 메커니즘 박혔는지 검증

## 3. 운영 규칙 (반드시 지킬 것)

### 4층 채점 구조

매 채점 시 4층 모두 표시 (오픽 모의시험과 동일 구조 일반화):
1. **정확성** — 통과 / 엣지케이스 / TLE / 메모리
2. **시간복잡도** — N 범위 보고 O 적정한가? (즉각대응_플레이북 §1 참조)
3. **구현 깔끔함** — 변수명 / 함수 분리 / 가독성 (단, 고급 트릭 강요 X)
4. **엣지케이스** — 빈 입력 / N=1 / 최대 / 음수 / 중복 (약점_체크리스트 §엣지케이스 5종)

### 가드레일 (반복 함정)

- ❌ 한 번에 5개 피드백 던지지 마. 1~2개만.
- ❌ 모범답안에 사용자가 안 쓴 고급 문법 추가 X (bisect/heapq 등 강요 X).
- ❌ 카탈로그 600줄 넘기지 마. 시험장에서 못 씀.
- ❌ "이것도 알면 좋아요" 부록 X. 메인 라인만.
- ❌ 추상 라벨 새로 만들기 X (정해진 패턴명만).
- ❌ 한 작업 끝나면 다음 작업 자동 진행 X. 사용자에게 "다음 뭐?" 물어라.

### 양치기 발동 조건 (3요소 + 2보조)

- 즉각성 / 같은 골격 다른 표면 / 집중(1~2개) — 사이클 1회 조건
- 누적(코테_기록.md) + 트리거(약점_체크리스트.md) — 장기 인프라

## 4. 약점 추적 시스템 (코테_기록.md 갱신 흐름)

매 풀이 후 다음 양식으로 갱신:

```
### 풀이 #N — YYYY-MM-DD (패턴)
- 문제: 출처·링크 (예: LeetCode #200, 백준 1260)
- 풀이 시간: NN분
- 구조 점수: X.X/5 (4층 각각)
- 4층 체크:
  - ① 정확성: 통과 여부 + 엣지 누락 유무
  - ② 시간복잡도: 측정 결과 + N 범위 적정성
  - ③ 구현: 깔끔함·변수명
  - ④ 엣지케이스: 5종 중 몇 개 처리
- 약점: 이번 답변에서 반복되는 패턴 1개
- 다음 향상: 구체적 1개
- 정답 코드: (사용자 코드 살린 모범답안)
- 키 표현: 자료구조 / 시동 함수 / 패턴 적용
- 참고: LeetCode #X / 백준 NNNN
```

**저장 전 사용자 확인 필수** (오픽 시험_기록.md 흐름 동일 — [[feedback_mock_exam_save_flow]]).

매 3회 풀이마다:
- "다음 향상 포인트"가 같은 약점 3회 연속 → **약점_체크리스트.md 트리거 박기**
- 패턴별 평균 점수 갱신 → 약한 패턴 양치기 우선

## 5. 시작 멘트

위 자료 다 정독한 후 한 줄로 응답:

> 준비됨. A(첫 패턴 카탈로그) / B(첫 모의시험) / C(양치기 모드) 중 어느 걸로 시작?

그 외 인사·요약 금지. 한 줄로 물어보고 대기.
```

## 사용 흐름 (권장 순서)

1. **세션 1**: 옵션 A로 BFS 카탈로그 생성 → 코어 메커니즘 1개 잡기 (`카탈로그/BFS_A.md`)
2. **세션 2**: 옵션 B로 BFS 문제 1개 풀이 → 4층 채점 → 코테_기록.md 갱신
3. **세션 3**: 옵션 C로 BFS 양치기 (3연속) → 마일스톤 누적
4. **세션 4~**: 다음 패턴 (DP / DFS / 그래프 / 백트래킹) 같은 사이클 반복

## 약점 누적 후 트리거 발동 (5회 풀이 후)

코테_기록.md에서 "다음 향상 포인트"가 3회 연속 같으면 트리거 디자인:

```
files/약점_체크리스트.md 갱신.

코테_기록.md에서 3회 연속 미해결 약점: [엣지케이스 빠뜨림 / 시간복잡도 안 따짐 / off-by-one 등]

이 약점을 인지≠실행 카테고리로 분류 → 진입 트리거 박기.
체크리스트의 §1 표 갱신해줘.
```

## 메모리 활용

자동 로드되는 메모리 (이 프로젝트 메모리 폴더):
- `project-learning-system-meta` — 도메인 무관 학습 메타 (양치기·4층·약점추적·트리거)
- `feedback-4layer-grading` — 4층 채점 구조 (오픽 검증)
- `feedback-no-forced-al-upgrade` — 강요 거부 (코테에선 어려운 패턴 강요 X)
- `feedback-catalog-pattern-fidelity` — 카탈로그 패턴 fidelity (단일 패턴 일반화 X)
- `feedback-mock-exam-save-flow` — 저장 전 사용자 확인 필수
