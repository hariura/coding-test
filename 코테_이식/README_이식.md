## 🚀 이식 절차

### 1. 폴더 통째로 이동

```bash
# 예: ~/Desktop/cote/로 옮기기
mv ~/Desktop/vs/코테_이식 ~/Desktop/cote

# 또는 다른 이름으로
mv ~/Desktop/vs/코테_이식 ~/Desktop/algorithm-study
```

내부 경로는 상대 경로(`agents/`, `files/`, `카탈로그/`)라 폴더명 무관하게 동작.

### 2. 메모리 이전 (Claude Code 사용 시)

새 폴더에서 처음 클로드 코드 세션 열면 `~/.claude/projects/-Users-jh-Desktop-cote/memory/`가 자동 생성됨 (폴더 이름이 cote라면).

그 후 다음 명령으로 메모리 이전:

```bash
# 새 폴더가 ~/Desktop/cote/ 인 경우
mkdir -p ~/.claude/projects/-Users-jh-Desktop-cote/memory/
mv ~/Desktop/cote/memory/project_learning_system_meta.md \
   ~/.claude/projects/-Users-jh-Desktop-cote/memory/

# MEMORY.md 인덱스 추가 (없으면 신규 생성)
echo "- [학습 시스템 메타 (도메인 무관)](project_learning_system_meta.md) — 오픽 IH 합격으로 검증된 양치기·4층채점·약점추적·트리거" \
  >> ~/.claude/projects/-Users-jh-Desktop-cote/memory/MEMORY.md
```

폴더 이름을 `cote`가 아닌 다른 이름으로 옮겼다면 그에 맞춰 경로 조정.

### 3. 빈 memory/ 폴더 정리 (선택)

이전 후 새 폴더의 `memory/` 비어있으면 삭제 가능:

```bash
rmdir ~/Desktop/cote/memory  # 비어있을 때만 성공
```
